# 🤖 CareerPilot AI

CareerPilot AI is an AI-powered web application that helps students generate personalized career roadmaps using Google's Gemini AI.

## 📌 Overview

Students often struggle with deciding what to learn, which projects to build, and how to prepare for placements.

CareerPilot AI solves this by generating personalized learning roadmaps based on:

- Branch
- Semester
- Current Skills
- Career Goal
- Weekly Study Hours

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Aditty02/CareerPilot-AI.git
```

Install dependencies

```bash
pip install flask flask-cors python-dotenv google-generativeai
```

Create an api.env file

```
GEMINI_API_KEY=YOUR_API_KEY
```

Run

```bash
python server.py
```
